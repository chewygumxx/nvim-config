COMMANDS                                                *nvim-config-commands*

User commands, all of them XX-prefixed. A [!] marks a command that takes a
bang and {args} one that takes arguments.

                                                    *nvim-config-insertheader*
:XXInsertHeader         Prepend buffer with a header, templated according to
                        filepath and extension.
                                                 *nvim-config-interpretescape*
:XXInterpretEscape[!]   Translate and interpret escape codes in terminal
                        buffer
                                                      *nvim-config-luachecker*
:XXLuaChecker {args}    Switch nvim-lint's lua type checker
                        (luals_check/emmylua_check); bare toggles
                                                         *nvim-config-mdtable*
:XXMdTable {args}       Markdown pipe tables
                        (format/buffer/left/center/right/none/toggle/enable/di
                        sable);
                        bare formats the one under the cursor
                                                         *nvim-config-nexnote*
:XXNexNote {args}       Notes in ~chewygumxx/nex.git
                        (new/commit/toggle/enable/disable); bare scaffolds a
                        new one
                                                    *nvim-config-redirautocmd*
:XXRedirAutocmd[!] {args}
                        Redirect to temporary buffer (bypass bang!): autocmd
                                                    *nvim-config-redircommand*
:XXRedirCommand[!] {args}
                        Redirect to temporary buffer (bypass bang!): command
                                                  *nvim-config-redirhighlight*
:XXRedirHighlight[!] {args}
                        Redirect to temporary buffer (bypass bang!): highlight
                                                        *nvim-config-redirmap*
:XXRedirMap[!] {args}   Redirect to temporary buffer (bypass bang!): map
                                                         *nvim-config-vistrav*
:XXVisTrav              Toggle: Visual traversal in current buffer
                                                  *nvim-config-vistravdisable*
:XXVisTravDisable       Disable: Visual traversal in current buffer
                                                   *nvim-config-vistravenable*
:XXVisTravEnable        Enable: Visual traversal in current buffer
                                                   *nvim-config-vistravtoggle*
:XXVisTravToggle        Toggle: Visual traversal in current buffer
                                                             *nvim-config-wip*
:XXWip[!] {args}        WIP snapshots to refs/wip/<branch>
                        (toggle/enable/disable/snapshot/drop); bare toggles

AUTOCOMMANDS                                        *nvim-config-autocommands*

Autocommands this configuration registers, by event.

BufDelete,BufWipeout    Release the buffer's WIP debounce timer
BufDelete,BufWipeout    Release the buffer's statusline resolve marker
BufFilePost             Forget a renamed buffer's WIP location
BufFilePost,BufWritePost
                        Invalidate the buffer's cached statusline git segment
BufNewFile              Designates new file buffer for pending header
                        insertion.
BufReadPost             Move cursor to last position within file
BufReadPost,BufEnter    For unmodifiable buffers: Keymap (nv) q->quit
BufWinEnter             Fold Claude Code's last-response context, if present
BufWritePost            Recompile a personal word list written by hand
BufWritePost            Stage and commit a written nex note
BufWritePost,BufLeave,FocusLost
                        Take a WIP snapshot at an editing checkpoint
BufWritePre             Re-box a plain header's repository and path on save
BufWritePre             Sync a Markdown header's title, mtime and box on save
FileType                If exists, implements filetype-specific configuration
FileType                Inserts templated header into new file buffer once
                        filetype is known.
FocusGained,VimResume,ShellCmdPost,TermClose
                        Invalidate every cached statusline git segment
InsertLeave,TextChanged Reformat the markdown table under the cursor
TextChanged,TextChangedI
                        Debounce a WIP snapshot of the changed buffer
VimEnter                Recompile a personal word list edited outside Neovim
